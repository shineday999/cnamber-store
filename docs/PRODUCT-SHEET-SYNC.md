# 商品 ⇄ Google 試算表：雙向自動同步（Apps Script 版）

> 不用 Google Cloud API。表格裡貼一段 Apps Script（`docs/sheet-sync/Code.gs`），兩邊就會互相同步。
> 下面「舊版：發布到網路 CSV」仍可使用，兩者可以並存。

## 同步規則

- **後台新增／保存商品**（基本資料改編號、翻譯、規格售價）→ 網站立刻把那一列寫進試算表；表格裡沒有就**新增一列**，slug 不用手抄。
- **試算表編輯儲存格** → 自動把那一列送到網站，寫進商品名稱／簡介／描述（4 語）和售價。「同步狀態」欄會顯示 ✓ 或 ✗ 與原因。
- **空白格不覆蓋**：表格某格是空的，不會清掉後台現有內容。
- slug 空白時，用「zh-Hans 名称」找商品（同名有多個會提示填 slug）。
- 兩邊都是「最後一次編輯為準」，因為每次編輯都立刻同步，不會累積衝突。
- 新語言要同時有名稱和描述才會新增；已存在的語言可以只改單一欄位。
- 售價是人民幣（元）；商品還沒有規格（後台「规格」頁沒存過）時，表格填的售價會被略過並提示。

## 試算表欄位（程式會自動補齊缺的標題）

`slug`、`名称（仅供参考）`、`<語言> 名称`、`<語言> 简介`、`<語言> 描述`（語言：zh-Hans、en、ms-MY、id-ID）、`售价`、`同步状态`

## 設定步驟（只做一次，約 5 分鐘）

1. 開啟試算表 → 擴充功能 → **Apps Script**，把 `docs/sheet-sync/Code.gs` 全部內容貼上取代原本的程式，存檔。
2. 回到試算表重新整理，選單多出 **商品同步** → **初始設定（只做一次）**：輸入網站網址，第一次會要求授權（選自己的帳號 → 進階 → 前往 → 允許）。完成後畫面會顯示一串**密鑰**，先複製。
3. 在專案目錄執行：
   - `pnpm exec wrangler pages secret put SHEET_SYNC_TOKEN --project-name=cnamber-store`，貼上密鑰。
4. 在 Apps Script 頁面：**部署 → 新增部署作業 → 類型選「網頁應用程式」**，「執行身分」選自己，「誰可以存取」選**任何人**，部署後複製**網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
5. 執行：`pnpm exec wrangler pages secret put SHEET_SCRIPT_URL --project-name=cnamber-store`，貼上網址。
6. 重新部署網站（merge 到 main 即自動部署），之後在試算表選單 **商品同步 → 全部同步到網站** 做第一次整張同步。

> 之後修改 `Code.gs` 需要在 Apps Script「部署 → 管理部署作業 → 編輯 → 新版本」，網頁應用程式才會用新程式。
> 網頁應用程式網址＋密鑰只有同時知道才能寫入；密鑰外洩請重新執行「初始設定」前先在 Script 屬性刪除 `TOKEN`，並更新 Cloudflare secret。

# 舊版：用 Google 試算表維護商品描述（發布到網路 CSV）

> 目的：商品的「一句话简介」「描述」（4 種語言）改在試算表維護，後台商品編輯頁的「翻译」頁籤按一下按鈕就讀回來填進欄位，再按「保存全部」存檔。

## 運作方式

1. 試算表（放在 Google Drive 的「龍蝦廣場」資料夾）每個商品一列。
2. 試算表用「發布到網路」輸出成 CSV 網址，網址存成 Cloudflare 的 secret `PRODUCT_SHEET_CSV_URL`。
3. 後台「翻译」頁籤的「从 Google 表格读取描述」按鈕 → `GET /api/admin/products/:id/sheet` → 依商品的 slug 找到那一列 → 把簡介、描述填進 4 種語言的欄位。
4. **只填進欄位，不會自動存檔**；檢查後按「保存全部」才會寫入資料庫。
5. 試算表裡**空白的格子不會覆蓋**後台現有內容。

## 試算表格式

第一列是標題列，欄位順序不拘，但名稱要完全一樣：

| 欄位標題                       | 說明                                                           |
| ------------------------------ | -------------------------------------------------------------- |
| `slug`                         | 商品編號，要和後台一致（後台商品編輯頁「基本」頁籤的唯讀欄位） |
| `名称（仅供参考）`             | 給自己看的，程式不讀                                           |
| `zh-Hans 简介`、`zh-Hans 描述` | 簡體中文                                                       |
| `en 简介`、`en 描述`           | 英文                                                           |
| `ms-MY 简介`、`ms-MY 描述`     | 馬來文                                                         |
| `id-ID 简介`、`id-ID 描述`     | 印尼文                                                         |

描述格子裡可以換行（Alt+Enter），前台會逐行顯示成段落。

## 設定步驟（只做一次）

1. 試算表：檔案 → 分享 → **發布到網路** → 選要發布的工作表、格式選 **逗號分隔值 (.csv)** → 發布，複製網址。
2. 在專案目錄執行 `pnpm exec wrangler secret put PRODUCT_SHEET_CSV_URL`，貼上網址。
3. 發布後的內容約有幾分鐘的延遲；試算表改完等一下再按按鈕。

## 後台入口

- 商品列表頁右上角「商品描述表格 ↗」、商品編輯頁「翻译」頁籤的「打开表格 ↗」，都會在新分頁打開這份試算表（需登入有編輯權限的 Google 帳號）。
- 網址寫在 `src/lib/sheet-sync.ts` 的 `PRODUCT_SHEET_EDIT_URL`；換檔案時改這裡。

## 注意

- 「發布到網路」的網址知道的人都能讀，內容只有商品簡介與描述（本來就會公開在前台），不要在這份表格放別的資料。
- 要停止同步：試算表「發布到網路」→ 停止發布。
