# 商品描述：用 Google 試算表維護（進度與設定）

> 目的：商品的「一句话简介」「描述」（4 種語言）改在試算表維護，後台商品編輯頁的「翻译」頁籤按一下按鈕就讀回來填進欄位，再按「保存全部」存檔。

## 運作方式

1. 試算表（放在 Google Drive 的「龍蝦廣場」資料夾）每個商品一列。
2. 試算表用「發布到網路」輸出成 CSV 網址，網址存成 Cloudflare 的 secret `PRODUCT_SHEET_CSV_URL`。
3. 後台「翻译」頁籤的「从 Google 表格读取描述」按鈕 → `GET /api/admin/products/:id/sheet` → 依商品的 slug 找到那一列 → 把簡介、描述填進 4 種語言的欄位。
4. **只填進欄位，不會自動存檔**；檢查後按「保存全部」才會寫入資料庫。
5. 試算表裡**空白的格子不會覆蓋**後台現有內容。

## 試算表格式

第一列是標題列，欄位順序不拘，但名稱要完全一樣：

| 欄位標題                       | 說明                                                           |
| ------------------------------ | -------------------------------------------------------------- |
| `slug`                         | 商品編號，要和後台一致（後台商品編輯頁「基本」頁籤的唯讀欄位） |
| `名称（仅供参考）`             | 給自己看的，程式不讀                                           |
| `zh-Hans 简介`、`zh-Hans 描述` | 簡體中文                                                       |
| `en 简介`、`en 描述`           | 英文                                                           |
| `ms-MY 简介`、`ms-MY 描述`     | 馬來文                                                         |
| `id-ID 简介`、`id-ID 描述`     | 印尼文                                                         |

描述格子裡可以換行（Alt+Enter），前台會逐行顯示成段落。

## 設定步驟（只做一次）

1. 試算表：檔案 → 分享 → **發布到網路** → 選要發布的工作表、格式選 **逗號分隔值 (.csv)** → 發布，複製網址。
2. 在專案目錄執行 `pnpm exec wrangler secret put PRODUCT_SHEET_CSV_URL`，貼上網址。
3. 發布後的內容約有幾分鐘的延遲；試算表改完等一下再按按鈕。

## 後台入口

- 商品列表頁右上角「商品描述表格 ↗」、商品編輯頁「翻译」頁籤的「打开表格 ↗」，都會在新分頁打開這份試算表（需登入有編輯權限的 Google 帳號）。
- 網址寫在 `src/lib/sheet-sync.ts` 的 `PRODUCT_SHEET_EDIT_URL`；換檔案時改這裡。

## 注意

- 「發布到網路」的網址知道的人都能讀，內容只有商品簡介與描述（本來就會公開在前台），不要在這份表格放別的資料。
- 要停止同步：試算表「發布到網路」→ 停止發布。
